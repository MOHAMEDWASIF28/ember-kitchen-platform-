Ember Kitchen: Online Food Ordering (Mini Project)
A front-end only food ordering app built with HTML, CSS, and vanilla JavaScript.
Features
Menu grouped by category with tabs
Live search by dish name or description
Slide-out cart with quantity controls, persisted in localStorage
Subtotal, delivery fee, and 8% tax calculation
Checkout form with validation
Order confirmation with a generated order ID and estimated arrival time
Orders saved to localStorage
How to run
Unzip the folder.
Open index.html in any modern browser. No server or install needed.
Customize
Edit dishes, prices, and categories in js/menu.js.
Change fees and tax rate at the top of js/menu.js.
Change colors and fonts in the :root block of css/style.css.
Ideas to extend

Add user login and order history
